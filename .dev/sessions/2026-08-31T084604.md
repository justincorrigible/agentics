Cut 0.19.0: moved rules with a natural trigger out of the always-read tier, gave corpus growth a measured budget enforced at the release commit, and repaired the cross-references those moves broke.

- `template/conventions/git.md`, `template/conventions/initialization.md`: new files holding the git rules and the one-time adoption steps previously loaded every session; reached from the dispatch table on a trigger instead, since a rule about writing a commit message is checked when a message is written
- `template/conventions/session-discipline.md`: 15,810 characters smaller as those sections plus the say-it-once, conformance-verification and permanent-override rules moved to the files that own them
- `template/conventions/writing-style.md`: succinctness is now the default for comments, commit messages, review comments and drafts, stated once here rather than three ways in three files; adds the addressing-versus-referring rule, prose as a serialization the reader reverses, and § One derivation, one owner, which decides which of two artifacts shipped together carries a derivation and which compresses to a pointer
- `template/conventions/agent-index.md`: an exchange ends when it stops changing the work rather than at the first acknowledgement; adds relayed requests, notices wanting no reply, and the rule that a handle is an address that no index field yields
- `template/conventions/review-conduct.md`: review comments are governed by what is included, in what order, in what container and how densely packed, each stated as a runnable test
- `template/conventions/security.md`: separates prescriptive guidance from diagnostic disclosure, covers remediation once a vulnerability is published, and treats a memory description as a broadcast
- `scripts/check-prune-ratio.sh`, `.githooks/commit-msg`: growth budget of 60,000 characters derived from four prior releases, fired on a release commit subject so it does not depend on being remembered; counts new files so relocating a section nets to zero, and reports the always-read share separately, unweighted because no derivable multiplier exists
- `testing/scripts/check-consistency.sh`: four advisory checks added, covering the release gate, prose density, generic labels where a name belongs, and zeroed session timestamps
- `testing/regression-checklist.md`: five scenarios added, including a truncating append that destroyed two convention files while every consistency check passed on the result
- `CONTRIBUTING.md`: the release procedure gained a manual cross-reference sweep for batches that move sections between files; an automated version was attempted and abandoned, since headings here carry backticked paths and numbered prefixes and every matcher traded one class of false positive for another
- `docs/deterministic-by-design.md`: adds what a convention costs as distinct from its size, a control whose failure looks like success, a rule whose test requires the judgement it produces, and a per-item test that cannot see an aggregate property
- `.dev/roadmap.md`: the growth item now records that the budget exists and that what remains open is the basis it measures, since the release grew the corpus by 150,877 characters while the always-read tier moved 1,825
