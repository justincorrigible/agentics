Cut 0.20.0: conventions drawn almost entirely from incidents reported by adopting projects, each carrying a checkable instance rather than a generalization.

- `template/conventions/code-style.md`: a type assertion is treated as a symptom pointing at a typing gap upstream rather than a local wart, since fixing what forced it removes every instance at once and deleting it locally relocates the same lie; documentation belongs in a declaration's own TSDoc block, with the named-type exception stated because TSDoc has no member tag, and a `/** */` on a statement inside a function body is an implementation comment wearing doc syntax
- `template/conventions/testing.md`: an expectation read off the implementation passes permanently and certifies whatever is there, so the requirement is stated first and the code checked against it; the question is what breaks if the assertion is wrong and whether anyone would notice, rather than whether the branch is covered; scoped to the expectation's provenance so a regression pin stays legitimate
- `template/conventions/review-conduct.md`: an absence is only as wide as the search that established it, with the three stores GitHub keeps review feedback in enumerated because a rule to search thoroughly cannot be executed and a list of three endpoints can; a question about change needs a baseline that was actually recorded, and identities are compared rather than counts, since an unchanged commit count is consistent with every commit having been replaced
- `template/conventions/git.md`: commit bodies are no longer hard-wrapped, one paragraph per line, recorded as a deliberate departure from the documented 72-column convention so nobody restores it; reflowing an existing message is a rewrite whose SHA changes exactly as a content change would, and a message-only rewrite is verified to have left the base commit, both trees and rename detection unchanged
- `template/conventions/writing-style.md`: succinctness now covers any document someone will act on, including design documents, roadmaps and indexes, after the existing scope proved unable to reach a single case that prompted it; attribution and edit dates go, sourcing goes once verified locally, and a confidence declaration stays because deleting one promotes second-hand to first-hand; the dash check reports its count, so a skipped check becomes a fabrication rather than a silence
- `template/conventions/agent-index.md`: conferral is the act and the display name is its record, so a spoken conferral obligates registering rather than waiting for a rename; pending confirmation is distinguished from unlabelled; seeing, owning and being are separated as three questions with three kinds of evidence; `main:` declares the space a head holds as distinct from where its expertise is; `for:` resolves through `owns:` and `main:` so a path reaches an owner or the head above them; a `heard:` names what satisfies the request in the terms the request used
- `template/conventions/upstream-check.md`: advancing a project's tag leaves every concurrently running session stale and removes the signal that would tell them, so the tag is treated as a value held and compared, and a sync notice is posted naming the repository
- `template/conventions/definition-of-done.md`: a stale read invalidates every claim resting on it rather than the one that surfaced, recategorising is not verifying, and a retraction is incomplete until it reaches everywhere the claim went, which only its author knows
- `template/conventions/entry-formats.md`: a session entry is held to what is unrecoverable from the pull request, the commits and the code, rather than being thinned or pointed at hosted content, since that would make a durable artifact depend on a disposable one
- `docs/deterministic-by-design.md`: stating a check explicitly does not make it fire, evidenced by a rule that names its own recurrence, was held in two places, and still did not run; the enforcement that exists covers files while the recurring failure is in outbound text that never becomes one
- `scripts/check-agent-index.sh`: reads declared heads and prints their nesting instead of inferring them from a broad ownership path, after the inference fell silent when a narrowed entry moved its headship into a field the script could not see, while still reporting no integrity problems
- `scripts/check-prune-ratio.sh`: measures the working tree, after reporting no growth across a batch of seventeen thousand characters that was correctly uncommitted between releases
- `testing/regression-checklist.md`: 15 scenarios added, covering a false delivery record, an unsound elimination over a deliberately incomplete registry, and an expectation copied out of the implementation it was meant to test
