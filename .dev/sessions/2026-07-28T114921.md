The multi-root case itself has no supported fix: Claude Code resolves a multi-root workspace's memory to whichever folder is listed *first* in the workspace file, for the whole window, regardless of active tab or member repo (confirmed empirically); the only workaround is a manual filesystem copy of the raw transcript, not something to rely on routinely
